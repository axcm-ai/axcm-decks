Workflow

How you ship a change

1
DesignSketch the page (or ask AI for a starting layout). You decide what goes live.
2
BuildEdit HTML/CSS in the repo — locally or with AI assistance. Preview before publish.
3
PublishPush to the hosting branch → Firebase updates the live public URL.
4
IterateRepeat. Small changes ship the same day. No portal release cycle.
